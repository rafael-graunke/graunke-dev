## Problem

Z70 is a fictional CPU architecture used to teach computer architecture at UCS. This project is a toolchain for it, written in Rust.

## How it works

Done so far:

- An assembly parser built with `nom`, with tests.
- A two-pass assembler, with tests.

## What's next / what I'd do differently

**Planned:**

- Emulator
- Disassembler
- Memory inspector
- REPL
- TUI debugger
- Public documentation of the architecture
