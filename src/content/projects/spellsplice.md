Editing MTG gameplay videos by hand was tedious, and the tool I wanted didn't exist, so I built it.

**What it does**

- Runs fully in the browser (Chromium-only), with no server-side rendering.
- Exports video in the browser using **WebCodecs** + **WebGL**.
- **Timeline mode:** syncs in-game events to exported match footage.
- **Live mode:** real-time overlay for OBS.
- Imports MTGO decklists.
